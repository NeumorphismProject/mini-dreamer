# 隐私政策路由管理文档

> 本文档记录所有通过本项目托管的纯静态隐私政策页面路由。
> 发布新 APP 时，可直接从此文档中取用对应的隐私政策路由 URL。

## 路由规则

- **基础路径**：`/privacy/{game-slug}`
- **game-slug**：游戏名称的拼音全拼（小写），如 `suanqufantang`
- **页面类型**：纯静态服务端组件，无客户端 JavaScript
- **导航入口**：不在首页、Header、Footer 或任何页面中添加链接入口，仅通过直接 URL 访问

## 新增隐私政策流程

1. 在 `src/app/privacy/{game-slug}/` 目录下创建 `page.tsx`
2. 编写纯静态隐私政策内容（服务端组件，不使用 `'use client'`）
3. 在上方路由清单中添加一行记录
4. 在 `README.md` 的隐私政策章节同步添加路由信息
5. 发布 APP 时，使用完整 URL（如 `https://你的域名/privacy/{game-slug}`）提供给应用商店审核
