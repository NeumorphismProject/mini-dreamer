# 协议路由管理文档

> 本文档记录所有通过本项目托管的纯静态协议页面路由（隐私政策、用户协议等）。
> 发布新 APP 时，可直接从此文档中取用对应的协议路由 URL。

## 路由规则

- **隐私政策**：`/privacy/{game-slug}`
- **用户协议**：`/agreement/{game-slug}`
- **game-slug**：游戏名称的拼音全拼（小写），如 `suanqufantang`
- **页面类型**：纯静态服务端组件，无客户端 JavaScript
- **导航入口**：不在首页、Header、Footer 或任何页面中添加链接入口，仅通过直接 URL 访问

## 新增协议流程

1. 在 `src/app/privacy/{game-slug}/` 或 `src/app/agreement/{game-slug}/` 目录下创建 `page.tsx`
2. 编写纯静态协议内容（服务端组件，不使用 `'use client'`）
3. 在上方对应路由清单中添加一行记录
4. 在 `README.md` 的协议路由章节同步添加路由信息
5. 发布 APP 时，使用完整 URL（如 `https://你的域名/privacy/{game-slug}`）提供给应用商店审核
